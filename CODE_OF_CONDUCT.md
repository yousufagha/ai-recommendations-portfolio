# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, stay on the work and assume good faith. Harassment and personal attacks are not accepted.

Report concerns through [GitHub's abuse form](https://github.com/contact/report-abuse). The repository owner may also remove content or block accounts that break these standards.
